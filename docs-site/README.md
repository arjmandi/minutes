# minutes — documentation site

The public user + admin documentation for [minutes](https://github.com/arjmandi/minutes),
built with [Docusaurus](https://docusaurus.io). It lives in the **private** repo so we can publish
it for everyone (e.g. at `docs.gettheminutes.com`) without putting the marketing/deploy specifics in
the open-source repo.

## Run locally

```bash
cd docs-site
npm install
npm start          # dev server with hot reload at http://localhost:3000
```

## Build the static site

```bash
npm run build      # outputs static HTML to build/
npm run serve      # preview the production build locally
```

Deploy `build/` to any static host (Netlify, Cloudflare Pages, GitHub Pages, or behind the same
Caddy box on a `docs.` subdomain).

## Structure

- `docs/` — the content (Markdown). The sidebar is **autogenerated** from the folder structure;
  ordering comes from each page's `sidebar_position` front-matter and the `_category_.json` files.
  - `intro.md`, `getting-started.md`
  - `admin/` — deploy, users, configuration
  - `users/` — web app, extension, meetings & export, uploads, sharing
  - `reference/` — languages, limitations, troubleshooting
- `docusaurus.config.js` — site config (title, navbar, footer, theme).
- `src/css/custom.css` — the warm-paper / flame-orange brand theme.
- `static/img/` — logo + favicon (the minutes mark).

## Editing

Pages are plain Markdown/MDX. Keep facts in sync with the code in the public repo — env-var names
(`app/config.py`), the admin CLI (`app/admin.py`), API behavior (`app/api/*`), and deploy
(`deploy/single-box/`). When you add a page, give it `sidebar_position` front-matter; the sidebar
picks it up automatically.
